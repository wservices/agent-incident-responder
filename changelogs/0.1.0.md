Initial scaffold release of the **incident-responder** role.

- Advisory, read-only Incident Response Analyst that owns the confirmed-incident
  lifecycle end to end per NIST SP 800-61r2.
- Seven bundled skills: incident triage & scoping, static malware triage (no
  detonation), forensic timeline reconstruction, IOC extraction & enrichment,
  SIEM/EDR alert correlation, containment/eradication/recovery *planning*
  (proposes, never executes), and NIST-style incident reporting + validated handoff.
- Receives escalations from the SOC Analyst (`security-analyst`); escalates major
  incidents to the Security Team Lead.
- APT tool layer (yara, sleuthkit, tshark, jq, ripgrep, exiftool) plus pip-only
  volatility3 and plaso/log2timeline documented in `tools/`.
- Optional read-only integrations: Wazuh SIEM (correlation) and VirusTotal / MISP
  (IOC enrichment, metadata only); all `env_requires` are optional.
