Deepened the **incident-responder** role from scaffold to a tested script layer.

Added offline, read-only, side-effect-free scripts under `scripts/` (stdlib +
PyYAML; each with an `argparse` CLI and `main(argv)`):

- `ioc_extract.py` — extract + defang IOCs (IPv4/IPv6, domains, URLs, emails,
  MD5/SHA1/SHA256); `--defang`/`--no-defang`/`--public-only`/`--json`. Adds
  `ipaddress`-based IPv6 validation so syslog times are not mis-read as IPv6.
- `timeline_build.py` — merge syslog, CSV (timestamp column), and `<ISO8601>
  <message>` events into ONE chronologically sorted, UTC-normalized super-timeline;
  every row tagged with its source file; `--json`/`--csv-out`.
- `static_triage.py` — SAFE static file triage, NO execution: MD5/SHA1/SHA256,
  file-type by magic bytes, printable-strings (`--min-len`), and URL/IP/suspicious-
  API heuristics.
- `incident_scope.py` — NIST SP 800-61r2 severity (Low/Medium/High/Critical) +
  priority (P1-P4) and scope counts from functional/information/recoverability
  impacts, via CLI flags or an incident YAML.
- `validate_handoff.py` — validate an incident `handoff.yaml` against the platform
  HANDOFF-FORMAT schema (required fields, enums, per-finding discipline, indicator
  dispositions).

Now script-backed: `ioc-extraction-and-enrichment`, `forensic-timeline-
reconstruction`, `static-malware-triage`, `incident-triage-and-scoping`, and
`incident-reporting` — each skill's `How to Run`, `Quick Reference`, and
`Verification` invoke the matching script (external tools retained where relevant);
those five skills bumped to 0.2.0.

Added behavior-contract tests under `tests/` (synthetic input → asserted output,
offline). `tests/test_scaffold.py` retained.
